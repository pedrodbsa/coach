| Segment | Distance | Pace | HR Target | Notes |
| ------- | -------- | ---- | --------- | ----- |
| Easy run | 4.5-5 km | 6:40-7:30/km | <148 bpm (outdoor) / <142 (treadmill) | Genuinely easy. RPE 3-4. Walk if HR buzzes. |
| Strides | 6 × 20s | Smooth acceleration to ~90% | N/A | Walk back 45-60s between each. Relaxed, not sprinting. |
| Cool-down | 500m | Walk | <120 bpm | |

**Execution notes:**
- **This is activation, not training.** The purpose is blood flow + neuromuscular priming. Nothing more.
- **After the peak weekend + rest day, expect stiff legs for km 1-2.** Don't judge the run until km 3. If it still feels heavy at km 3, skip the strides and just jog home.
- **Strides: 90% effort, NOT a sprint.** Smooth acceleration, hold for 20s, decelerate. Focus on form — high knees, relaxed shoulders, quick turnover. The goal is neural activation, not cardiovascular stress.
- **If outdoor:** MAF ceiling is 148 bpm. Run wherever is flat and comfortable. Don't turn this into a route exploration day.
- **Do NOT extend beyond 5km base + strides.** No "feeling good so I'll do 8km." Taper discipline matters.

**HR context from Sunday's long run:** Your avg was 158 for 19km. Today must NOT be anywhere near that. If you see 150+ at easy pace, walk. The body needs easy to actually be easy this week.
