**Timing:** After lunch (~14:00-15:00) | **Duration:** 45-50 min | **Intensity:** RPE 7-8

| #   | Exercise            | Sets x Reps | Weight              | Rest    |
| --- | ------------------- | ----------- | ------------------- | ------- |

| 2   | Overhead Press      | 3 x 8-12    | Find RPE 7-8        | 2 min   |
| 3   | Incline DB Press    | 3 x 10-15   | 14-18 kg            | 90 sec  |
| 4   | Bench Dips          | 3 x 12-15   | +10 kg plate on lap | 90 sec  |
| 5   | Lateral Raises      | 3 x 12-15   | 6-7 kg              | 60 sec  |
| 6a  | Ab Wheel Rollout    | 3 x 8-10    | Bodyweight          | 60 sec  |
| 6b  | Hanging Knee Raise  | 3 x 10-12   | Bodyweight          | 60 sec  |

**Notes:**

- Exercises rotated from Feb 11 (was: DB Bench 18kg, Arnold Press 10-12kg, Cable Flyes, Dips BW, Lat Raises 6-7kg)
- **Barbell Bench:** First time in this cycle. Start conservative — warm up empty bar → 40kg → working sets. Find RPE 7-8.
- **OHP:** Standing, strict press. Start light, find the groove.
- **Incline DB Press:** 30-45 degree incline, controlled tempo.
- **Bench Dips +10kg:** Place a 10kg plate on your lap. Hands on bench behind you, feet on floor (or elevated on another bench for more ROM). Target 12-15 reps. If +10kg feels like RPE 8+, drop to bodyweight — alcohol tax today.
- **Ab Wheel Rollout:** From knees. Brace core, extend as far as possible without arching lower back. If no ab wheel, substitute Dead Bug.
- **Hanging Knee Raise:** Control the swing, slight pause at top.
- Core categories: anti-extension (Ab Wheel) + flexion (Hanging Knee Raise)
- **Log every weight.**
